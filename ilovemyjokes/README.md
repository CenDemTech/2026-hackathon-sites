# ilovemyjokes

**Attendee:** [@ilovemyjokes](https://github.com/ilovemyjokes)

**Project:** Folio — search museum collections that release public domain art under CC0 (the Met, Art Institute of Chicago, Cleveland Museum of Art, SMK), check the image against your print size, frame it, and print it as a poster. Designed in Claude Design. The site is `index.html`.
