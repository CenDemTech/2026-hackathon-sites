# mikeendrias-coder

**Attendee:** Michael Endrias (Intern) — [@mikeendrias-coder](https://github.com/mikeendrias-coder)

**Project:** *Face Value* — an interactive walkthrough of state facial recognition laws. Pick a state, who is searching (local, state or federal) and with what (photo source and database), then follow one investigation step by step to see where state law protects people, where it only partly does, and where nothing does. Includes guided stories, state comparisons, "what if" scenarios using pending bills, and a searchable table of every law, bill and quoted provision.

- `index.html` — full interactive version
- `simple.html` — simpler one-page version
- `data.js` — data generated from the State Facial Recognition Laws and Bills research (current through Oct. 26, 2026)
- `icons/` — pixel-art icons

Prototype, not legal analysis.
