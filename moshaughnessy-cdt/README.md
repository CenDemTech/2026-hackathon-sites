# moshaughnessy-cdt

**Attendee:** [@moshaughnessy-cdt](https://github.com/moshaughnessy-cdt)

**Project:** *The Fine Print* — an explainer showing how quiet rewrites of federal Privacy Act System of Records Notices (SORNs) opened the door to reported data misuse, with redlines of each notice change. Designed in Claude Design; the site is `index.html`.

- `index.html`: page layout and styles
- `cases.js`: the four case studies (edit text here)
- `app.js`: builds the case pages and redlines
