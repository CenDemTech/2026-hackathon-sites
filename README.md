# 2026-hackathon-sites
Repository of CDT's first staff hackathon held on November 11, 2026!

## Projects

| Attendee folder | Project | Live page |
| --- | --- | --- |
| [abhatia-ops](abhatia-ops/) | **The Bean Jar**: a counting game from the world's pantries. Estimate how many beans are in each of six jars, guess which region cooks with that bean, and learn a classic dish for each. | [View site](https://cendemtech.github.io/2026-hackathon-sites/abhatia-ops/) |
| [atonull](atonull/) | **Drift: Bedtime Story Generator**: pick a setting, a mood and a sleep timer, and Drift builds a slow-paced bedtime story and reads it aloud, fading out gently when the timer ends. | [View site](https://cendemtech.github.io/2026-hackathon-sites/atonull/) |
| [czembo](czembo/) | **Red Planet Ledger**: an interactive log of 196 two-player Terraforming Mars games, shown on a spinning globe of Mars with overall statistics and corporation performance. | [View site](https://cendemtech.github.io/2026-hackathon-sites/czembo/) |
| [drewcourtney](drewcourtney/) | **The Spirit Parlour**: an interactive Victorian séance. Choose a spirit to summon, ask it a question, and watch the parlour answer with knocks, bells, a tilting table and planchette messages. | [View site](https://cendemtech.github.io/2026-hackathon-sites/drewcourtney/) |
| [drwokkawokka](drwokkawokka/) | **Crowdpleaser**: a karaoke song picker that ranks songs by how many people in the room know them. | [View site](https://cendemtech.github.io/2026-hackathon-sites/drwokkawokka/) |
| [hannahqd](hannahqd/) | **Inkwell Swatches**: a browsable library of fountain pen ink swatches, filterable by color family, with "I own this" and wishlist tracking and a form to add your own inks. | [View site](https://cendemtech.github.io/2026-hackathon-sites/hannahqd/) |
| [ilovemyjokes](ilovemyjokes/) | **Folio**: search museum collections that release public domain art under CC0, check the image against your print size, frame it, and print it as a poster. | [View site](https://cendemtech.github.io/2026-hackathon-sites/ilovemyjokes/) |
| [kaldridge-tech](kaldridge-tech/) | **Clark's Closet Dash**: a time-management game where Clark, Hollywood's most stylish shop dog, seats A-list guests, pulls the looks they want from the racks, and collects the cash. | [View site](https://cendemtech.github.io/2026-hackathon-sites/kaldridge-tech/) |
| [michal-luria](michal-luria/) | **Personal website** for Michal Luria. | [View site](https://cendemtech.github.io/2026-hackathon-sites/michal-luria/) |
| [mikeendrias-coder](mikeendrias-coder/) | **Face Value**: an interactive walkthrough of state facial recognition laws. Follow one investigation step by step to see where state law protects people, where it only partly does, and where nothing does. | [View site](https://cendemtech.github.io/2026-hackathon-sites/mikeendrias-coder/) |
| [moshaughnessy-cdt](moshaughnessy-cdt/) | **The Fine Print**: an explainer showing how quiet rewrites of federal Privacy Act System of Records Notices (SORNs) opened the door to reported data misuse, with redlines of each notice change. | [View site](https://cendemtech.github.io/2026-hackathon-sites/moshaughnessy-cdt/) |
| [quinnar-cdt](quinnar-cdt/) | **Byte vs. the Data Grabbers**: a data privacy adventure game where Byte, a robot cat, takes on trackers, dark patterns, data brokers and a data-hoarding boss across four mini-games. | [View site](https://cendemtech.github.io/2026-hackathon-sites/quinnar-cdt/) |
