# kaldridge-tech

Hackathon project by @kaldridge-tech.

**Clark's Closet Dash** — a time-management game where Clark, Hollywood's most stylish shop dog, seats A-list guests, pulls the looks they want from the racks, and collects the cash. Designed in Claude Design and built with Claude Code.

- `index.html` — the playable game (scales to fit any screen; best sideways on phones)
- `avatar.html` — Clark's character card
- `clark.svg` — Clark's portrait, used in both pages
