# abhatia-ops

**The Bean Jar**: a counting game from the world's pantries. Estimate how many beans are in each of six jars, guess which region cooks with that bean, and learn a classic dish for each.

Originally designed in Claude Design, then converted to a single plain `index.html` (no build step) so it can be hosted on GitHub Pages.

## Run it locally

From the repository root:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/abhatia-ops/> in your browser. Press `Ctrl+C` in the terminal to stop the server.
